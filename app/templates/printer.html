Waar vind ik deze gegevens?
  1. Ga op het scherm van de P1S naar Instellingen → WLAN / Netwerk. Daar staan het IP-adres en de toegangscode (Access Code).
  2. Het serienummer staat onder Instellingen → Apparaat, in Bambu Studio bij het apparaat, of op de sticker achterop.
  3. Op recente firmware (01.08.02 en nieuwer) moet je LAN-only mode en daarna Developer Mode aanzetten (zelfde menu). Anders weigert de printer software van derden. In LAN-only mode werkt Bambu Handy / de cloud niet; Bambu Studio werkt wel via LAN.
  4. Geef de printer bij voorkeur een vast IP-adres in je router.

Zo werkt het: via MQTT (poort 8883) volgt de app de printstatus en de AMS-sloten. Bij het starten en afronden van een print wordt het printbestand via FTPS (poort 990) van de printer gehaald. Uit slice_info.config leest de app per filament het aantal gram. Bij een afgebroken print wordt het geprinte deel afgeschreven (verbruik × voortgang).
